# Laboratorio-Defense-in-Depth
El siguiente apartado trata sobre una infraestructura bastionada creada mediante máquinas virtuales en VirtualBox.
Para la creación de esta infraestructura, se han precisado 4 máquinas virtuales: 
- un pfSense para conectar y gestionar el tráfico entre máquinas.
- un Ubuntu Server para alojar el servicio web a bastionar.
- un Kali Linux como atacante externo.
- un Lubuntu para las configuraciones web de pfSense.
